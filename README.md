# Garima Chauhan | Portfolio

Personal site for my work in AI governance, ethics, and safety.

**Live:** https://

## Built with
- Plain HTML, CSS, and JavaScript in a single file, with no frameworks or build step
- EB Garamond via Google Fonts
- A canvas starfield with cursor-reactive constellations, plus scroll animations

## Run it locally
Open `index.html` in a browser.

## Edit it
- Projects: copy a `card-wrap` block in the Projects section and edit the text.
- Colors: the palette lives in the `:root` block at the top of the file.

## Deploy
Hosted on Vercel. Pushing to `main` redeploys automatically.
