About

I've become increasingly aware of how much damage AI can do when it's misused, from deepfakes to AI-powered scams to cyberattacks. The same technology that makes AI so useful is what makes it dangerous in the wrong hands, and I can't stop thinking about that.

That's why I want to build in cybersecurity, AI governance, and ethics instead of studying the problem from the sidelines. I'm a computer science student at Northeastern University with an AI concentration, and my research on LLM accountability and transparency led me to start building projects like mcp-trustcheck, a scanner that flags risky MCP servers before developers connect their AI tools to them.

I'm also a creative person. I love art, media, and design, and it shows up in how I build, from the AI Club's brand to this site.

Break Through Tech AI Studio

An LLM auditor that checks software requirements against NASA's NPR 7150.2, using retrieval and structured output verification so each verdict cites the clause behind it.

mcp-trustcheck

An MCP server trust scanner

Flags risky or malicious MCP servers before developers connect their AI tools to them. The static layer is built, with six checks per tool and fuzzy matching for look-alike names. A runtime layer is planned.

Static layer built. Python, Next.js, Vercel, Supabase.
